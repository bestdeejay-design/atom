# Спайки этапа 0

Три проверки до начала разработки. Они отвечают на вопросы, от которых зависят ADR-0002 и ADR-0004.

| Спайк | Вопрос | Файл |
|---|---|---|
| 1. TextKit 2 | Тянет ли `NSTextView` файлы 100 МБ и 1 ГБ: открытие, прокрутка, ввод? Нужен ли свой Metal-слой? | `Sources/TextKitSpike` |
| 2. tree-sitter | Подсветка в AppKit: время разбора и обновления | **Не написан.** Нужна зависимость SwiftTreeSitter и грамматики; добавим отдельным шагом после первого замера |
| 3. JavaScriptCore | Плагины: стоимость, песочница по разрешениям, останавливается ли бесконечный цикл | `Sources/JSCSpike` |

## Требования

- Mac с Apple Silicon.
- macOS 14 или новее (для сборки спайков). Для целевого продукта — macOS 26 (ADR-0006), спайки это не меняет.
- Xcode 15.3 или новее (`xcode-select --install` достаточно для `swift`).
- Около 3 ГБ свободного места на диске: тестовые файлы создаются во временной папке.

## Запуск

Из корня репозитория:

```bash
cd native/spikes
swift run -c release TextKitSpike | tee results-textkit.txt
swift run -c release JSCSpike     | tee results-jsc.txt
```

Результаты пишутся в `results-*.txt` внутри `native/spikes/`. Файлы добавлены в `.gitignore`, в коммит не попадают. Цифры переносим в `docs/NATIVE-SPIKE-RU.md` вручную или присылаем сюда.

### Что будет на выходе

- **TextKit:** для каждого размера — время чтения, установки текста, первой разметки, p50/p95/max для прокрутки и ввода, RSS процесса.
- **JSC:** стоимость контекста, вызов нативной функции, проверку песочницы, ошибки плагина и результат теста бесконечного цикла.

## Как читать результаты

**TextKit 2 (критерии для решения):**
- Ввод: p95 ниже 16 мс — отлично (60 кадров/с), до 33 мс — приемлемо, выше — кандидат на свой Metal-слой.
- Прокрутка: p95 ниже 16 мс — отлично.
- Открытие 1 ГБ: если установка текста занимает больше нескольких секунд или память растёт непропорционально, включаем режим больших файлов (E-17 в фич-листе) и ищем альтернативу.

**JSC (критерии):**
- Пункт 2b должен показать `undefined / undefined / undefined`. Иначе песочница протекла.
- Пункт 6: если цикл не останавливается сам, значит, нужен механизм лимита времени. Это ожидаемый результат, а не провал спайка. Варианты перечислены в ADR-0004 (добавить в раздел «Последствия»).

## Если что-то не собралось

Пришлите полный вывод `swift run` в этот чат. Скорее всего, нужна правка под вашу версию Xcode, код не проверялся компилятором.
