# Architecture Decision Records (ADR)

Здесь фиксируются архитектурные решения нового редактора. Каждое решение — отдельный файл.
Старые документы (`docs/*-RU.md` про Atom Lite) описывают **прошлую** работу над форком и на новый проект не влияют, кроме случаев, явно указанных в ADR.

## Статусы

- **Принято** — действует, менять только новым ADR.
- **Предложено** — рабочая рекомендация, ждёт подтверждения владельца.
- **Открыто** — вопрос без рекомендации.
- **Заменено** — отменено более новым ADR (ссылка указана в файле).

## Формат

Каждый ADR содержит: контекст, решение, альтернативы, последствия, как проверить.
Новый ADR получает следующий номер. Старый не переписывается, а помечается «Заменено».
