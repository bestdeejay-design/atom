# ADR-0002. Нативный стек: Swift, AppKit, SwiftUI, без веб-технологий

**Статус:** Принято
**Дата:** 2026-10-15

## Контекст

Задача: редактор, который ощущается как Mac-приложение. Electron, Chromium и Node исключены: они дают лишний вес, фоновые процессы и веб-поведение (масштабирование, IME, шрифты, контекстные меню), которое выглядит чужим.

Тренды 2026 (подробнее в плане): редакторы уходят от веб-движков к GPU-рендерингу (Zed на Metal), Apple вводит Liquid Glass и концентричность углов для AppKit и SwiftUI, tree-sitter становится стандартом подсветки.

## Решение

| Слой | Технология | Почему |
|---|---|---|
| Язык | **Swift 6** | Нативно, строгая многопоточность, нет рантайма вне системы |
| Текст | **AppKit + TextKit 2** | IME, VoiceOver, системное выделение, проверка орфографии уже работают |
| Окна, панели, настройки | **SwiftUI**, где это уместно | Меньше кода для форм и списков |
| Подсветка и структура | **tree-sitter** (Swift-биндинги) | Структурный разбор вместо регулярных выражений |
| Языковые серверы | **LSP-клиент** собственный | Протокол небольшой, лишние зависимости не нужны |
| Git | **Системный `git`** через `Process` | Не тащим git в бандл |
| Плагины | См. ADR-0004 | JavaScriptCore — системный фреймворк |
| Веб-вью | **Не используем** в интерфейсе | Исключение только через отдельный ADR (например, предпросмотр HTML) |

**Запрещено в ядре и интерфейсе:** Electron, Chromium, WKWebView для UI, Node.js, сторонние UI-фреймворки на JavaScript.

## Альтернативы

- **Свой Metal-рендерер текста** (как Zed/GPUI). Отложено: сначала измеряем TextKit 2 на больших файлах. Если не тянет, открываем отдельный ADR.
- **Чистый SwiftUI для редактора.** Отклонено: недостаточный контроль над текстом, IME и производительностью на больших файлах.
- **Rust + собственный UI.** Отклонено: вся платформенная интеграция (меню, IME, VoiceOver, Liquid Glass) придётся писать вручную.

## Последствия

- Минимальная версия macOS зависит от ADR-0006 (Liquid Glass есть в macOS 26+).
- Нужен Xcode на машине сборки; CI — GitHub Actions на раннерах macOS.
- Переносимость на другие ОС не цель. Linux и Windows не поддерживаем.

## Как проверить

- В бинарнике нет `Electron Framework.framework`, `node`, `libnode`.
- Ни одного `WKWebView` в дереве интерфейса (grep по `WKWebView`).
- Холодный старт и ввод замеряются инструментами Xcode (Time Profiler, Instruments), а не на глаз.
