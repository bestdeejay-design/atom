# ADR-0005. Сеть и приватность: по умолчанию ноль соединений

**Статус:** Принято
**Дата:** 2026-10-15

## Контекст

Принцип «автономность» из Atom Lite сохраняется и становится частью концепции тишины (ADR-0003). Сеть нужна редко: ИИ-агенты, загрузка плагинов по ссылке, стор (позже). Всё остальное должно работать без неё.

## Решение

1. **Редактор не делает сетевых запросов сам.** Нет автообновления, проверки версии, телеметрии, сбора статистики, отчётов о сбоях с отправкой.
2. **Обновления — только вручную.** Пользователь скачивает новую версию сам. Кнопка «Проверить обновления» не существует в первой версии; вместо неё — страница релизов в документации.
3. **Сеть разрешается только явным действием:**
   - запуск внешнего ИИ-агента, который сам ходит в сеть (агент — отдельный процесс, его сеть — его ответственность, но редактор показывает, что агент запущен);
   - установка плагина по URL;
   - (позже) обновление индекса стора — только по нажатию.
4. **Плагины** получают сеть только через capability `network` и разрешение на домен (ADR-0004).
5. **Сбои.** Журнал ошибок пишется локально в `~/Library/Logs/<App>/`. Отправка — только вручную, пользователем, через сохранение файла для вложения в письмо или issue.
6. **Данные пользователя** остаются на Mac: тексты, история, настройки, журнал. Облачной синхронизации нет.

## Альтернативы

- **Телеметрия с согласием.** Отклонено: даже с согласием появляется фоновое соединение, а тишина это запрещает.
- **Автообновление через Sparkle.** Отклонено: фоновая проверка нарушает ADR-0003. Можно вернуть позже как опцию, выключенную по умолчанию, отдельным ADR.

## Последствия

- Поддержка пользователей идёт через журнал ошибок и ручное приложение файлов.
- Исследовательские данные о том, как пользуются редактором, не собираются. Решения о фичах принимаются по обратной связи, а не по метрикам.

## Как проверить

- Сниффинг сетевого трафика (Little Snitch или `nettop`) на протяжении 10 минут простоя и обычной работы: ноль соединений от процесса редактора.
- Grep по коду: нет вызовов `URLSession`, кроме разрешённых модулей (ИИ-агенты, загрузка плагинов). Список разрешённых модулей ведётся в этом ADR.
- В бандле нет SDK телеметрии и отчётов о сбоях.
