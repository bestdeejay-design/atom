# ADR-0006. Минимальная версия macOS

**Статус:** Открыто
**Дата:** 2026-10-15

## Контекст

От этого решения зависит, какие API доступны. Liquid Glass (`NSGlassEffectView`, `glassEffect`) появился в macOS 26 и продолжает развиваться в macOS 27 (WWDC26: изменения scroll edge effect, концентричность углов). Чем выше минимум, тем проще код, но меньше пользователей.

## Варианты

| Вариант | Что даёт | Что теряем |
|---|---|---|
| **A. macOS 26+** | Liquid Glass, новые API AppKit, меньше кода совместимости | Пользователи на macOS 15 и старше |
| **B. macOS 15+** | Широкая аудитория, все современные AppKit/TextKit 2 | Стекло — только имитация или отказ от него |
| **C. macOS 14+** | Максимальная аудитория | TextKit 2 и часть API придётся обходить |

## Предварительная рекомендация

**Вариант A (macOS 26+).** Редактор пишется сейчас, и поддержка старых версий тянет за собой условные ветки кода. Тишина и Liquid Glass при этом не конфликтуют: стекло используется только для плавающих элементов (ADR-0003, правило 5).

Альтернатива — **B**, если владелец ожидает пользователей на Mac с более старыми системами.

## Что нужно решить

- Какой Mac будет основной рабочей машиной владельца (от этого зависит, что можно проверить вживую).
- Есть ли среди ожидаемых пользователей Mac, которые не обновляются до macOS 26.

## Как проверить после решения

- Сборка и запуск на минимальной версии, обозначенной здесь.
- На более новой версии (macOS 27): визуальная проверка стекла и scroll edge effect.
