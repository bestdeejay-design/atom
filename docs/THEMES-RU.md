# Темы: «dajet» и «joer»

Две темы форка. Сделаны парами: тема интерфейса задаёт цвета окна и содержит
настройки, тема подсветки их читает — поэтому пара выглядит цельно, а не как
чужие половинки.

| Пакет | Что это | Роль |
|---|---|---|
| `packages/dajet-ui` | тема интерфейса | тёплое светлое стекло и матовый почти-чёрный; терракота — единственный акцент |
| `packages/dajet-syntax` | тема подсветки | тёплые сдержанные цвета; терракотой — ключевое |
| `packages/joer-ui` | тема интерфейса | тёмная основа всегда + пять атмосфер: lounge, club, romantic, space, velvet |
| `packages/joer-syntax` | тема подсветки | цвет атмосферы — на ключевом; содержание набрано спокойными тёплыми тонами |

Все четыре — обычные пакеты Atom в `packages/` и подключены как встроенные
(`package.json` → `dependencies` и `packageDependencies`, замок обновлён).
**По умолчанию включена пара `dajet-ui` + `dajet-syntax`** —
`src/config-schema.js`, ключ `core.themes`. Темы `joer` выбираются в настройках,
как и 12 прежних тем Atom: они не удалены и по-прежнему весят 1.1 МБ на всех
(решение владельца — оставлять или снимать их «диетой»).

---

## Откуда взяты цвета

Ничего не выдумано: палитры сняты с двух проектов серии, клоны лежат вне
репозитория, в `/home/user/design` (в репозиторий не попадают — они не наши).

| Тема | Источник | Что именно взято |
|---|---|---|
| `dajet` | `dajet-player`, `Sources/DajetPlayer/Design.swift` | `Palette` (ground, ink, accent, onAccent — светлая и тёмная пары), `Metrics` (строка 26, угол 8, панель 12, колонка 232), `Motion` (spring, easeOut) |
| `joer` | сайт `joer.ru`, `css/tokens.css` и `css/themes/*.css` | фон, поверхности, границы, три ступени текста, акцент, второй акцент, кольцо фокуса — по каждой из пяти атмосфер; радиусы 6/10/16 и время 120/220 мс |

Чего у источников нет — отмечено в самих файлах как наше: свечение окна
(`--joer-glow-a/b`) и мягкая подложка выбранной строки (`--joer-wash`)
выведены из акцентов атмосферы с той же плотностью, что `--accent-soft` на
сайте. Цвета состояний (info/success/warning/error) в серии отсутствуют —
взяты тёплыми и приглушёнными, с контрастом ≥ 4.5:1 к своему фону.

## Как это выбирается и настраивается

Настройки темы видны там же, где у остальных тем: **Settings → Themes**
(так устроена тема `one-dark-ui`, это штатный механизм Atom — `configSchema`
в `package.json`).

| Настройка | Значения | По умолчанию |
|---|---|---|
| `dajet-ui` → «Облик» | `system` / `dark` / `light` | `system` — как в macOS |
| `dajet-ui` → «Размер шрифта интерфейса» | 11…16 | 13 |
| `joer-ui` → «Атмосфера» | `lounge` / `club` / `romantic` / `space` / `velvet` | `lounge` |
| `joer-ui` → «Атмосферная подсветка окна» | вкл/выкл | вкл |
| `joer-ui` → «Размер шрифта интерфейса» | 11…16 | 13 |

Как это работает. В `lib/main.js` темы нет ничего, кроме одного действия:
настройку превратить в признак на `<html>` — `data-dajet-look="…"` или
`data-joer-atmosphere="…"`. Весь цвет живёт в LESS и включается по признаку:

```less
:root                                  { /* тёмный облик — по умолчанию */ }
html[data-dajet-look="light"]          { /* светлый облик */ }
@media (prefers-color-scheme: dark) {
  html[data-dajet-look="system"]       { /* за системой следит сама система */ }
}
```

Три решения, которые здесь важно не потерять:

* **Признак — атрибут на `<html>`, а не класс на рабочей области.** Тема
  обязана красить и то, что рисуют чужие пакеты (дерево файлов, строку
  состояния, настройки, всплывающие подсказки) — а им нужен признак, видимый
  из любой точки документа.
* **«Как в системе» ничего не слушает.** Ни обработчиков, ни опросов: в LESS
  есть медиазапрос `prefers-color-scheme`, и окно меняется вместе с Mac само.
* **Цвет в правилах — только через `var(--…)`.** LESS считает цвета один раз
  при сборке стилей, а облик обязан меняться на ходу. Поэтому арифметики над
  цветом в правилах тем нет — она осталась только в договоре (см. ниже).

## Из чего состоит тема

```
packages/dajet-ui/
  package.json      имя, тип темы, настройки (облик, размер шрифта)
  lib/main.js       ставит data-dajet-look на <html>
  index.less        точка входа: подключает styles/ по порядку
  styles/palette.less        цвета серии парами: светлая и тёмная
  styles/ui-variables.less   договор с чужими пакетами (настоящие цвета)
  styles/looks.less          облики: как цвета попадают в переменные CSS
  styles/chrome.less         правила: из чего складывается окно

packages/dajet-syntax/
  styles/syntax-variables.less  договор: цвета для чужих пакетов
  styles/looks.less             облики подсветки (тёмный / светлый)
  styles/editor.less            поверхность редактора, курсор, жёлобы
  styles/syntax.less            правила подсветки
```

`joer` устроен так же, только вместо двух обликов — пять атмосфер
(`styles/atmospheres.less`), а у подсветки тёплые тона содержания объявлены
ею самой: они **не зависят от атмосферы нарочно** — иначе в `club` страница
кода стала бы малиновой целиком.

## Договор с чужими пакетами

Главная тонкость тем Atom. Чужие стили читают переменные темы и **считают из
них оттенки** — `lighten(@text-color, 15%)`, `darken(@button-background-color,
5%)`, `fade(@syntax-color-added, 30%)`. Таких мест в пакетах форка — 184.
Арифметику над `var()` LESS не умеет, поэтому:

* `ui-variables.less` и `syntax-variables.less` содержат **настоящие цвета** —
  это и есть договор;
* правила тем берут цвет из `var(--…)`, чтобы облик менялся на ходу.

Проверено, что договор полный: каждая тема объявляет **все** имена базового
набора Atom — 56 имён интерфейса (`static/variables/ui-variables.less`) и
30 имён подсветки (`static/variables/syntax-variables.less`). Тема подсветки
читает у своей пары интерфейса немногое: `dajet` — три переменные
(`--dajet-base`, `--dajet-ink`, `--dajet-accent`), `joer` — девять (фон,
текст, тихий текст, приглушённый, два акцента, кольцо, подложка, линия).
Все они объявлены, и у каждой есть запасное значение из LESS — поэтому даже
неправильная пара (например, `dajet-syntax` с чужим интерфейсом) читается,
а не рассыпается.

## Как это проверяется

```bash
node script/check-themes.js      # нужен script/bootstrap (он ставит less)
node script/preview-themes.js    # собрать theme-preview.html и открыть в браузере
```

Инструмент `script/check-themes.js` проверяет четыре вещи:

1. **компиляцию** каждой темы тем же LESS 2.7 и теми же путями импорта, что
   и сам Atom (иначе проверка проверяет не то);
2. **договор**: собирает пробный «чужой пакет», который берёт переменные темы
   и считает из них оттенки — как это делают настоящие пакеты;
3. **базовый набор**: что тема объявила все имена `static/variables/*`;
4. **переменные CSS**: что нет ни одного `var(--…)`, которому не нашлось
   объявления.

Тот же скрипт — шагом в сборке (`.github/workflows/build.yml`, «Проверка тем»)
перед долгой сборкой: секунды против часа, а ошибка в теме ломает окно целиком.

**Текущий результат** (всё чисто):

```
Проверка тем: компиляция LESS
  dajet-ui      → собрано 14.3 КБ, 454 строк
  dajet-syntax  → собрано 7.9 КБ, 290 строк
  joer-ui       → собрано 12.9 КБ, 410 строк
  joer-syntax   → собрано 5.2 КБ, 208 строк

Проверка тем: договор с чужими пакетами
  чужой пакет с темой dajet-ui + dajet-syntax → компилируется
  чужой пакет с темой joer-ui + joer-syntax → компилируется

Проверка тем: базовый набор переменных
  dajet-ui      → базовый набор: 56 имён, все на месте
  joer-ui       → базовый набор: 56 имён, все на месте
  dajet-syntax  → базовый набор: 30 имён, все на месте
  joer-syntax   → базовый набор: 30 имён, все на месте

Проверка тем: переменные CSS
  dajet-ui      → переменные CSS: 23 чтений, все есть
  dajet-syntax  → переменные CSS: 20 чтений, все есть
  joer-ui       → переменные CSS: 24 чтений, все есть
  joer-syntax   → переменные CSS: 13 чтений, все есть

Всё чисто.
```

### Посмотреть глазами

```bash
node script/preview-themes.js
```

Собирает `theme-preview.html` (в репозиторий не попадает — он в `.gitignore`):
макет окна Atom с настоящими именами классов (`atom-workspace`, `.pane-item`,
`.tab-bar`, `.tree-view`, `.status-bar`, `atom-text-editor`) и теми же
собранными файлами тем. Переключатели на странице ставят на `<html>` те же
атрибуты, что и `lib/main.js` тем, поэтому видно и работу переключения:
облик `dajet` (как в системе / тёмный / светлый), пять атмосфер `joer`,
подсветка окна вкл/выкл. Это **макет**, а не снимок редактора: шрифты и
мелочи вёрстки могут отличаться.
