# Фич-лист нативного редактора

**Что это:** полный список возможностей, которые редактор может иметь. Список — основа для решений, а не обещание.
**Как читать:**

- **Приоритет:** `MVP` — входит в первую рабочую версию; `v1` — после MVP; `Later` — возможно, потом; `Нет` — сознательно не делаем.
- **Тишина:** `✓` — соответствует ADR-0003; `!` — требует особого внимания (что именно — в примечании).
- Каждая фича либо есть в списке, либо явно отклонена. Фичи, которых нет в списке, добавляются через правку этого файла.

Ссылки на ADR: [0001](adr/0001-clean-room-rewrite.md) чистый лист · [0002](adr/0002-native-stack.md) стек · [0003](adr/0003-silence-principle.md) тишина · [0004](adr/0004-plugin-model.md) плагины · [0005](adr/0005-network-and-privacy.md) сеть · [0006](adr/0006-platform-target.md) версия macOS

## Сводка по приоритетам

- **MVP:** текст, поиск, проекты и файлы, подсветка, базовый git (гаттер и диффы), плагины с разрешениями, тишина, сборка.
- **v1:** LSP, выбор языков второй волны, панели, стор-ready плагины, отдельные функции ИИ с подтверждением.
- **Later:** отладка, терминал, полноценный git, on-device модель, стор.
- **Нет:** всё, что противоречит тишине или ADR-0005 (уведомления, автообновления, телеметрия, проактивный ИИ).

## Что сознательно не входит в концепцию

- Облачная синхронизация, совместное редактирование в реальном времени, удалённая разработка по SSH.
- Проактивный ИИ, автогенерация текста без вызова.
- Публичная телеметрия и метрики использования.
- Встроенный магазин приложений как обязательная часть продукта.
