# joer-syntax

Тема подсветки «joer»: цвет атмосферы — на ключевом; строки, числа и типы
набраны спокойными тёплыми тонами, одинаково читаемыми во всех пяти
атмосферах.

Работает парой с `joer-ui` и берёт у неё цвета атмосферы. Если рядом чужая
тема интерфейса — пользуется собственными значениями базовой атмосферы
`lounge`.

Полное описание — `docs/THEMES-RU.md` в корне репозитория.
