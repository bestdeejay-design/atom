# dajet-syntax

Тема подсветки «dajet»: тёплые сдержанные цвета; терракотой отмечено
ключевое — как в плеере серии отмечено важное, а не всё подряд.

Работает парой с `dajet-ui`: поверхность, текст и терракота берутся у неё
(`--dajet-base`, `--dajet-ink`, `--dajet-accent`), поэтому подсветка меняется
вместе с обликом интерфейса. Если рядом чужая тема интерфейса — берутся
собственные значения, тема остаётся читаемой.

Полное описание — `docs/THEMES-RU.md` в корне репозитория.
