# dajet-ui

Тема интерфейса «dajet»: тёплое светлое стекло и матовый почти-чёрный,
терракота — единственный акцент. Цвета, расстояния и время движения сняты
с плеера серии (`Sources/DajetPlayer/Design.swift`).

## Настройки

| Настройка | Значения | По умолчанию |
|---|---|---|
| Облик | `system` (как в macOS) / `dark` / `light` | `system` |
| Размер шрифта интерфейса | 11…16 | 13 |

Облик — это атрибут `data-dajet-look` на `<html>`; цвета живут в LESS и
включаются по нему. «Как в системе» не следит ни за чем вручную: за него
отвечает медиазапрос `prefers-color-scheme`.

Полное описание, договор с чужими пакетами и проверка — `docs/THEMES-RU.md`
в корне репозитория.
