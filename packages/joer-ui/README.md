# joer-ui

Тема интерфейса «joer»: тёмная основа и пять атмосфер — `lounge`, `club`,
`romantic`, `space`, `velvet`. Цвета сняты с сайта joer.ru
(`css/tokens.css`, `css/themes/*.css`).

## Настройки

| Настройка | Значения | По умолчанию |
|---|---|---|
| Атмосфера | `lounge` / `club` / `romantic` / `space` / `velvet` | `lounge` |
| Атмосферная подсветка окна | вкл / выкл | вкл |
| Размер шрифта интерфейса | 11…16 | 13 |

Атмосфера — атрибут `data-joer-atmosphere` на `<html>`. Подсветка окна —
статичный кадр сцены (два тихих свечения за панелями), без движения.

Полное описание — `docs/THEMES-RU.md` в корне репозитория.
